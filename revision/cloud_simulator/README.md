# 风与湿度云量估计器

这是一个本地可交互的统计原型：输入同一时刻的 **850 hPa 区域平均水平风和比湿**，估计该区域的 **整层总云量**。第一版界面与正式模型只支持同一时刻（horizon=0），没有把同刻估计称为未来预报。

## 打开

双击本目录 `Open_Cloud_Simulator.cmd`。启动器使用已有虚拟环境，在后台启动仅监听 `127.0.0.1:8765` 的服务，并优先使用 Google Chrome 打开。模型与输入都在本机处理，不上传、不调用在线模型。

也可在仓库根目录运行：

```powershell
& '../.venv/Scripts/python.exe' 'revision/cloud_simulator/app.py'
```

然后访问 <http://127.0.0.1:8765/>。前台运行时按 Ctrl+C 停止。关闭网页不会停止后台 Python 服务；启动器的进程编号和日志保存在模型目录。

## 输入和输出

- 风可输入 u/v（m/s），或风速与气象风向（来向，0°北风、90°东风）。服务端转换为 `u=-speed*sin(direction)`、`v=-speed*cos(direction)`。
- 湿度是**比湿 q，单位 g/kg**，不是相对湿度 RH%。不能直接填地面天气站的风和相对湿度。
- 基础模型只使用 u/v/q；情境模型再使用所选地区与公历月份。基础模式下，地区与月份只用于显示历史平均基线。
- 输出云量百分比和80%名义预测区间。区间不是均值置信区间，相关样本及分布变化下不保证达到80%覆盖。界面展示历史测试覆盖率。
- 可扫描比湿画响应曲线、载入固定训练期实例、导出带单位及限制条件的 JSON 结果。示例的 ERA5 实际云量不是独立验证。
- 外推检查只能发现一部分不受训练资料支持的输入；通过检查不代表可靠。

## 数据与评价

复用 `revision/weather_tokens/data.py` 读取的原单位 ERA5 区域均值，不使用旧的全时期标准化数组。仍为固定12个粗区域，每日00 UTC，训练1979–2014、校准2015–2018、回顾测试2019–2025。按已有保守窗口规则排除跨资料段边界的起报点。地区等权，不能解释成面积加权全球表现或站点级预测。

均值和分位数梯度提升树的超参数事先固定；不使用测试集调参。地区×月份均值基线与全局均值基线只由训练样本计算。80%分位区间仅用校准期的非负扩展量校准。误差用云量百分点表示；与此前云量增减分类的Brier分数不是同一任务，不能直接比较。

模型、协议、预测、指标、输入哈希及审计保存在 `../revision_outputs/cloud_simulator_v1/`（相对于仓库）。该研究已查看过2019–2025资料，因此本轮是回顾性评价，并非从未查看过的确认试验。来源处理方式在2023年变化，需同时检查分段指标。原气压层没有地下层遮罩，区域也未做面积权重；这些限制未因建立界面而消失。

## 科学解释

本轮回顾测试平均绝对误差：只用风湿为9.115个百分点，加入情境为6.859个百分点，地区×月份均值基线为7.293个百分点。80%名义区间实际覆盖分别为77.74%和77.49%；情境模型晚期覆盖73.48%。这意味着地区与季节背景本身解释了相当多的云量差异，额外风湿信息的描述性改善仍较小。未进行显著性检验，也不宣称普遍超过所有基线。

本模型估计的是训练资料中的条件统计关系。一个高度的风和比湿不能唯一决定整层云量；未输入的温度、垂直运动、稳定度及气候背景仍可能造成较大误差。界面改变输入产生的响应，不是可识别的干预或大气因果效应，也不含流体方程、云微物理积分或三维云场模拟。

定义依据：[ECMWF 总云量](https://codes.ecmwf.int/grib/param-db/164)、[ERA5 数据说明](https://confluence.ecmwf.int/pages/viewpage.action?pageId=185075432)。

## 接口

`GET /api/metadata` 返回地区、模型范围、示例和历史测试指标；`POST /api/predict` 返回估计及训练支持提示。示例：

```json
{"wind_input":"uv","u_mps":8,"v_mps":0,"humidity_gkg":6,"mode":"wind_humidity","horizon_hours":0,"region_id":46,"month":7}
```

`POST /api/sweep` 接受相同输入，加 `sweep_min_gkg` 和 `sweep_max_gkg`，返回25个湿度状态。`engine.py` 的 `CloudEstimator` 可直接在Python中使用。训练命令以 `engine.py --help` 为准；已经存在的正式训练产物不会被静默覆盖。
