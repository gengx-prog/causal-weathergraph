# Manuscript sources

Author: Xinchen Geng, University of Southern California.

Install Python 3 and a LaTeX distribution with `pdflatex` and `bibtex` on your PATH. The sources use the included Elsevier class and standard LaTeX packages, including the display dependencies generated by `latexdiff` for the marked manuscript.

Run from this directory:

```sh
python build.py
```

This compiles the clean manuscript, marked manuscript and supplementary material into `.build/`, and exits with an error if compilation, BibTeX or final reference checks fail. To build one document, pass its filename without `.tex`, for example `python build.py Causal_WeatherGraph_revised`.

The marked manuscript preserves changes relative to the original local manuscript and includes the union of the old and revised bibliography. All required figures and table sources are included. The submission PDFs and machine-readable supplementary data are in `../submission_20261002/` in the repository; the supplementary data are distributed separately from this source archive.
